# Digital Pass — الموقع الإلكتروني

موقع تعريفي لشركة **Digital Pass** (مفتاحك إلى العالم الرقمي)، مبني بالكامل على دليل الهوية البصرية v1.0.
الموقع عربي أولاً (RTL) مع نسخة إنجليزية بزر واحد، ويعمل على الجوال والكمبيوتر.

موقع ثابت بالكامل (HTML + CSS + JavaScript) — لا يحتاج سيرفر ولا خطوات بناء.

## الأقسام

| القسم | المحتوى |
|---|---|
| الرئيسية | العنوان «مفتاحك إلى العالم الرقمي» مع رمز الشعار الكبير كما في غلاف دليل الهوية |
| من نحن | «التقنية الجيدة لا تُرى…»، النبذة، الرؤية والرسالة |
| خدماتنا | **الأنظمة والتطبيقات:** الأنظمة المخصّصة · تطوير التطبيقات · إدارة التطبيقات · الحلول الرقمية<br>**المواقع والمتاجر الإلكترونية:** تطوير المواقع · حلول متاجر سلة · ثيمات مخصّصة |
| ماذا نبني | واجهات توضيحية مبنية بالكود: لوحة تحكم، تطبيق جوال، متجر إلكتروني |
| طريقة عملنا | نفهم ← نصمّم ← نبني ← نشغّل |
| لماذا Digital Pass | القيم الأربع: الثقة · الوضوح · الإتقان · الشراكة |
| تواصل معنا | زر واتساب كبير + نموذج طلب استشارة يُرسل عبر واتساب |

## هيكل الملفات

```
index.html              الصفحة (المحتوى العربي موجود هنا مباشرة)
assets/css/style.css    التصميم — الألوان والخطوط والمسافات من دليل الهوية
assets/js/config.js     ← إعدادات التواصل (الملف الوحيد الذي تحتاج تعديله للربط)
assets/js/i18n.js       النصوص الإنجليزية
assets/js/main.js       تبديل اللغة، القائمة، النموذج، الحركة
assets/img/             الرمز، أيقونة المتصفح، صورة المشاركة، أيقونة واتساب
```

## الربط (التواصل)

كل شيء في `assets/js/config.js`:

```js
formEndpoint: "",                 // رابط استقبال النموذج (اختياري)
whatsapp: "966532883201",         // رقم خدمة العملاء — بدون + — يُستخدم في wa.me
email: "",                        // مخفي
phone: "",                        // مخفي
location: { ar: "", en: "" },     // مخفي
social: { linkedin: "", x: "", instagram: "" }
```

- التواصل حالياً **عبر واتساب فقط**: زر كبير في قسم «تواصل معنا»، ورابط في الفوتر، وزر عائم أخضر في زاوية الشاشة — كلها تفتح محادثة مع رقم `whatsapp`.
- أي قيمة فارغة `""` يُخفى عنصرها تلقائياً (مثلاً: أيقونات الحسابات لا تظهر حتى تضيف روابطها، وأزرار واتساب تختفي إذا كان الرقم فارغاً).
- أيقونة واتساب (`assets/img/whatsapp.svg`) من مكتبة [Bootstrap Icons](https://icons.getbootstrap.com) (رخصة MIT).

### نموذج التواصل

- **بدون `formEndpoint`**: عند الإرسال يُفتح واتساب لدى الزائر برسالة جاهزة فيها تفاصيل الطلب إلى رقم `whatsapp` (وإذا كان الرقم فارغاً يُفتح تطبيق البريد إلى `email`).
- **مع `formEndpoint`**: يُرسل النموذج طلب `POST` بصيغة `FormData`، ويعرض رسالة نجاح أو خطأ.
  يعمل مباشرة مع أي خدمة تقبل FormData، مثل:
  - [Formspree](https://formspree.io): `https://formspree.io/f/xxxxxx`
  - [Web3Forms](https://web3forms.com): `https://api.web3forms.com/submit` (أضف حقل `access_key` مخفياً في النموذج)
  - Google Apps Script (لحفظ الطلبات في Google Sheets)
  - أو API خاص بكم

الحقول المرسلة: `name`, `company`, `email`, `phone`, `service`, `service_label`, `message`, `language`, `page`.
يحتوي النموذج على حقل مخفي لاصطياد رسائل السبام (`website`) — لا يُرسل.

## التشغيل محلياً

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

لعرض النسخة الإنجليزية مباشرة: `index.html?lang=en`

## النشر

الموقع ثابت، فيمكن نشره على GitHub Pages أو Netlify أو Vercel أو أي استضافة عادية.

**GitHub Pages:** Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.

## ملاحظات على الهوية

- الرمز (حرف P بثقب المفتاح والبكسلات الثلاث) مرسوم بـ SVG وفق نسب «بناء الشعار» في الدليل (ص 9).
  إذا توفرت ملفات الشعار الرسمية (SVG)، يُفضّل استبدال الرمز في `index.html` (`#dp-symbol`) وفي `assets/img/` بها.
- الاسم المكتوب «DIGITAL PASS» معروض بخط IBM Plex Sans Bold؛ الدليل ينص أن الاسم رسم ثابت — يُستبدل بملف الشعار الرسمي عند توفره.
- الخطوط: IBM Plex Sans Arabic / IBM Plex Sans / IBM Plex Mono من Google Fonts.
- التدرّج: `linear-gradient(150deg, #1FC8F6 0%, #2D63FC 100%)` — يُستخدم للخلفيات الكبيرة والعناوين الكبيرة فقط.
