# Digital Pass: الموقع الإلكتروني

موقع تعريفي لشركة **Digital Pass** (مفتاحك إلى العالم الرقمي)، مبني بالكامل على دليل الهوية البصرية v1.0.
الموقع عربي أولاً (RTL) مع نسخة إنجليزية بزر واحد، ويعمل على الجوال والكمبيوتر.

موقع ثابت بالكامل (HTML + CSS + JavaScript)، لا يحتاج سيرفر ولا خطوات بناء.

## الصفحة الرئيسية

| القسم | المحتوى |
|---|---|
| الرئيسية | العنوان «مفتاحك إلى العالم الرقمي» مع رمز الشعار الكبير كما في غلاف دليل الهوية |
| من نحن | «التقنية الجيدة لا تُرى…»، النبذة، من نخدم (الأفراد والشركات الصغيرة والمتوسطة فقط، في السعودية ودول الخليج)، الرؤية والرسالة |
| خدماتنا | **الأنظمة والتطبيقات:** الأنظمة المخصّصة · تطوير التطبيقات · إدارة التطبيقات · الحلول الرقمية<br>**المواقع والمتاجر الإلكترونية:** تطوير المواقع · حلول متاجر سلة · ثيمات مخصّصة<br>كل خدمة تفتح صفحتها التفصيلية |
| ماذا نبني | واجهات توضيحية مبنية بالكود: لوحة تحكم، تطبيق جوال، متجر إلكتروني |
| طريقة عملنا | نفهم ← نصمّم ← نبني ← نشغّل |
| لماذا Digital Pass | القيم الأربع: الثقة · الوضوح · الإتقان · الشراكة |
| تواصل معنا | بطاقة اتصال برقم ظاهر، بطاقة واتساب، وأوقات العمل |

## صفحات الخدمات

| الرابط | الصفحة | خدمات الرئيسية المرتبطة بها |
|---|---|---|
| `/services/salla/` | حلول متاجر سلة والثيمات المخصصة | حلول متاجر سلة، ثيمات مخصّصة |
| `/services/mobile-apps/` | تطوير تطبيقات الجوال | تطوير التطبيقات، إدارة التطبيقات |
| `/services/websites/` | تصميم وتطوير المواقع | تطوير المواقع |
| `/services/custom-systems/` | الأنظمة المخصصة ولوحات التحكم | الأنظمة المخصّصة، الحلول الرقمية |

كل صفحة فيها: مقدمة الخدمة، ماذا نقدّم (6 بطاقات)، لمن هذه الخدمة، طريقة عملنا، أسئلة شائعة، التواصل، وروابط الخدمات الأخرى.

- **النص العربي** داخل ملف الصفحة نفسه (`services/<الصفحة>/index.html`)، و**النص الإنجليزي وعنوان الصفحة بالإنجليزي** في `assets/js/i18n-services.js`.
- الهيدر والفوتر وقسما «طريقة عملنا» و«تواصل معنا» منسوخة من `index.html`. **إذا عدّلتها في الرئيسية، عدّلها كمان في الصفحات الأربع.**
- كل صفحة لها عنوانها ووصفها ورابطها الأساسي (canonical) وبياناتها المنظمة الخاصة (Service و BreadcrumbList).

## هيكل الملفات

```
index.html                  الصفحة الرئيسية (المحتوى العربي موجود هنا مباشرة) + البيانات المنظمة لمحركات البحث
services/<الصفحة>/index.html صفحات الخدمات الأربع
404.html                    صفحة «غير موجودة» (عربي وإنجليزي)
robots.txt, sitemap.xml     ملفات محركات البحث
_headers                    يمنع أرشفة نسخ pages.dev (الأرشفة للدومين digital-pass.co فقط)
assets/css/style.css        التصميم: الألوان والخطوط والمسافات من دليل الهوية
assets/js/config.js         ← رقم التواصل وروابط الحسابات (الملف الوحيد الذي تحتاج تعديله لتغييرها)
assets/js/i18n.js           النصوص الإنجليزية للرئيسية والأجزاء المشتركة
assets/js/i18n-services.js  النصوص الإنجليزية لصفحات الخدمات
assets/js/main.js           تبديل اللغة، القائمة، روابط التواصل، الحركة
assets/img/                 الرمز، أيقونة المتصفح، صورة المشاركة، أيقونة واتساب
```

## التواصل

الرقم والحسابات كلها في `assets/js/config.js`:

```js
phone: "+966532883401",        // رقم الاتصال بالصيغة الدولية
phoneDisplay: "053 288 3401",  // الرقم كما يظهر للزائر
whatsapp: "966532883401",      // بدون +، يُستخدم في wa.me
social: { linkedin: "", x: "" }
```

- التواصل **بالاتصال وواتساب فقط**، بدون نموذج: بطاقتان في قسم «تواصل معنا» (الاتصال أولاً ثم واتساب)، ونفس الروابط في الفوتر، وزر واتساب عائم أخضر في زاوية الشاشة.
- **إذا غيّرت الرقم**، غيّره كمان في البيانات المنظمة (`application/ld+json`) داخل `index.html`.
- **أوقات العمل** (الأحد إلى الخميس، من 9:00 صباحاً حتى 4:30 عصراً) نص عادي: العربي في `index.html` وصفحات الخدمات، والإنجليزي في `assets/js/i18n.js` تحت `contact.hoursDays` و `contact.hoursTime`.
- أيقونة واتساب (`assets/img/whatsapp.svg`) من مكتبة [Bootstrap Icons](https://icons.getbootstrap.com) (رخصة MIT).

### حسابات لنكد إن و X

أيقونتا الحسابات جاهزتان، ومخفيتان حتى تضيف الروابط:

1. في `assets/js/config.js` ضع الرابط الكامل لكل حساب:
   ```js
   social: { linkedin: "https://www.linkedin.com/company/...", x: "https://x.com/..." }
   ```
   الأيقونات تظهر تلقائياً في قسم «تواصل معنا» وفي الفوتر بكل الصفحات. إذا تركت حساباً فارغاً `""` تبقى أيقونته مخفية.
2. أضف نفس الروابط في البيانات المنظمة داخل `index.html`، داخل كتلة `Organization`:
   ```json
   "sameAs": ["https://www.linkedin.com/company/...", "https://x.com/..."]
   ```
   هذا يساعد قوقل يربط الحسابات بالشركة.
3. غيّر رقم النسخة `?v=` (انظر الفقرة التالية) عشان يشوف الزوار التعديل فوراً.

## محركات البحث (SEO)

- عنوان الرئيسية: «Digital Pass | بناء وتطوير الحلول الرقمية المتعددة» (في `index.html`، وفي `assets/js/i18n.js` تحت `meta`). عناوين صفحات الخدمات في ملف كل صفحة، والإنجليزي منها في `assets/js/i18n-services.js`.
- البيانات المنظمة (Organization و WebSite) في رأس `index.html`: الاسم، الشعار `assets/img/logo-512.png`، الرقم، أوقات العمل، الخدمات مع روابط صفحاتها، ومنطقة الخدمة (السعودية ودول الخليج).
- `sitemap.xml` فيه الرئيسية وصفحات الخدمات الأربع. حدّث `lastmod` إذا غيّرت محتوى صفحة بشكل كبير، وأضف أي صفحة جديدة.
- **بعد أي تعديل على ملفات CSS أو JS** غيّر رقم النسخة `?v=` في `index.html` و `404.html` وصفحات الخدمات الأربع (حالياً `20261111d`). Cloudflare يخلي المتصفح يحتفظ بهذي الملفات 4 ساعات، وتغيير الرقم يضمن إن الزوار ياخذون النسخة الجديدة فوراً.
- كل نص في الموقع يتحول مع زر اللغة. أي نص جديد يحتاج `data-i18n` (أو `data-i18n-html`) وترجمته في `assets/js/i18n.js` (أو `i18n-services.js` لصفحات الخدمات).

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

روابط الملفات تبدأ بـ `/`، فشغّل الموقع بسيرفر محلي مثل الأمر أعلاه بدل فتح الملف مباشرة.
لعرض النسخة الإنجليزية مباشرة: أضف `?lang=en` لأي رابط.

## النشر

الموقع منشور على **Cloudflare Pages** ومربوط بهذا المستودع:

- أي تعديل يُدفع إلى فرع `main` يُنشر تلقائياً على `digital-pass.co` خلال دقيقة تقريباً.
- أي فرع آخر يأخذ رابط معاينة خاص: `https://<اسم-الفرع>.digital-pass.pages.dev` (غير مؤرشف في قوقل).
- `www.digital-pass.co` يحوّل إلى `digital-pass.co` بقاعدة تحويل في Cloudflare.

## ملاحظات على الهوية

- الرمز (حرف P بثقب المفتاح والبكسلات الثلاث) مرسوم بـ SVG وفق نسب «بناء الشعار» في الدليل (ص 9).
  إذا توفرت ملفات الشعار الرسمية (SVG)، يُفضّل استبدال الرمز في `index.html` وصفحات الخدمات (`#dp-symbol`) وفي `assets/img/` بها.
- الاسم المكتوب «DIGITAL PASS» معروض بخط IBM Plex Sans Bold؛ الدليل ينص أن الاسم رسم ثابت، فيُستبدل بملف الشعار الرسمي عند توفره.
- الخطوط من Google Fonts: IBM Plex Sans Arabic للعربية، Inter للإنجليزية، IBM Plex Mono للأرقام الصغيرة، و IBM Plex Sans لاسم الشعار «DIGITAL PASS» فقط.
- التدرّج: `linear-gradient(150deg, #1FC8F6 0%, #2D63FC 100%)` يُستخدم للخلفيات الكبيرة والعناوين الكبيرة فقط.
