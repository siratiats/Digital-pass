# Digital Pass — الموقع الإلكتروني

موقع تعريفي لشركة **Digital Pass** (مفتاحك إلى العالم الرقمي)، مبني بالكامل على دليل الهوية البصرية v1.0.
الموقع عربي أولاً (RTL) مع نسخة إنجليزية بزر واحد، ويعمل على الجوال والكمبيوتر.

موقع ثابت بالكامل (HTML + CSS + JavaScript) — لا يحتاج سيرفر ولا خطوات بناء.

## الأقسام

| القسم | المحتوى |
|---|---|
| الرئيسية | العنوان «مفتاحك إلى العالم الرقمي» مع رمز الشعار الكبير كما في غلاف دليل الهوية |
| من نحن | «التقنية الجيدة لا تُرى…»، النبذة، من نخدم (الأفراد والشركات الصغيرة والمتوسطة فقط)، الرؤية والرسالة |
| خدماتنا | **الأنظمة والتطبيقات:** الأنظمة المخصّصة · تطوير التطبيقات · إدارة التطبيقات · الحلول الرقمية<br>**المواقع والمتاجر الإلكترونية:** تطوير المواقع · حلول متاجر سلة · ثيمات مخصّصة |
| ماذا نبني | واجهات توضيحية مبنية بالكود: لوحة تحكم، تطبيق جوال، متجر إلكتروني |
| طريقة عملنا | نفهم ← نصمّم ← نبني ← نشغّل |
| لماذا Digital Pass | القيم الأربع: الثقة · الوضوح · الإتقان · الشراكة |
| تواصل معنا | بطاقة اتصال برقم ظاهر، بطاقة واتساب، وأوقات العمل |

## هيكل الملفات

```
index.html              الصفحة (المحتوى العربي موجود هنا مباشرة) + البيانات المنظمة لمحركات البحث
404.html                صفحة «غير موجودة» (عربي وإنجليزي)
robots.txt, sitemap.xml ملفات محركات البحث
_headers                يمنع أرشفة نسخ pages.dev (الأرشفة للدومين digital-pass.co فقط)
assets/css/style.css    التصميم — الألوان والخطوط والمسافات من دليل الهوية
assets/js/config.js     ← أرقام التواصل (الملف الوحيد الذي تحتاج تعديله لتغيير الرقم)
assets/js/i18n.js       النصوص الإنجليزية
assets/js/main.js       تبديل اللغة، القائمة، النموذج، الحركة
assets/img/             الرمز، أيقونة المتصفح، صورة المشاركة، أيقونة واتساب
```

## التواصل

الأرقام كلها في `assets/js/config.js`:

```js
phone: "+966532883401",        // رقم الاتصال بالصيغة الدولية
phoneDisplay: "053 288 3401",  // الرقم كما يظهر للزائر
whatsapp: "966532883401",      // بدون +، يُستخدم في wa.me
social: { linkedin: "", x: "", instagram: "" }
```

- التواصل **بالاتصال وواتساب فقط**، بدون نموذج: بطاقتان في قسم «تواصل معنا» (الاتصال أولاً ثم واتساب)، ونفس الروابط في الفوتر، وزر واتساب عائم أخضر في زاوية الشاشة.
- أي قيمة فارغة `""` يُخفى عنصرها تلقائياً (مثلاً: أيقونات الحسابات لا تظهر حتى تضيف روابطها).
- **إذا غيّرت الرقم**، غيّره كمان في البيانات المنظمة (`application/ld+json`) داخل `index.html`.
- **أوقات العمل** (الأحد إلى الخميس، من 9:00 صباحاً حتى 4:30 عصراً) نص عادي: العربي في `index.html` والإنجليزي في `assets/js/i18n.js` تحت `contact.hoursDays` و `contact.hoursTime`.
- أيقونة واتساب (`assets/img/whatsapp.svg`) من مكتبة [Bootstrap Icons](https://icons.getbootstrap.com) (رخصة MIT).

## محركات البحث (SEO)

- عنوان الصفحة: «Digital Pass | بناء وتطوير الحلول الرقمية المتعددة» (في `index.html`، وفي `assets/js/i18n.js` تحت `meta`).
- البيانات المنظمة (Organization و WebSite) في رأس `index.html`: الاسم، الشعار `assets/img/logo-512.png`، الرقم، أوقات العمل، والخدمات.
- `sitemap.xml` فيه رابط الصفحة الرئيسية؛ حدّث `lastmod` إذا غيّرت المحتوى بشكل كبير، أو أضف أي صفحة جديدة.
- كل نص في الموقع يتحول مع زر اللغة. أي نص جديد يحتاج `data-i18n` (أو `data-i18n-html`) وترجمته في `assets/js/i18n.js`.

## التشغيل محلياً

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

لعرض النسخة الإنجليزية مباشرة: `index.html?lang=en`

## النشر

الموقع ثابت، فيمكن نشره على GitHub Pages أو Netlify أو Vercel أو أي استضافة عادية.

**GitHub Pages:** Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.

## ملاحظات على الهوية

- الرمز (حرف P بثقب المفتاح والبكسلات الثلاث) مرسوم بـ SVG وفق نسب «بناء الشعار» في الدليل (ص 9).
  إذا توفرت ملفات الشعار الرسمية (SVG)، يُفضّل استبدال الرمز في `index.html` (`#dp-symbol`) وفي `assets/img/` بها.
- الاسم المكتوب «DIGITAL PASS» معروض بخط IBM Plex Sans Bold؛ الدليل ينص أن الاسم رسم ثابت — يُستبدل بملف الشعار الرسمي عند توفره.
- الخطوط من Google Fonts: IBM Plex Sans Arabic للعربية، Inter للإنجليزية، IBM Plex Mono للأرقام الصغيرة، و IBM Plex Sans لاسم الشعار «DIGITAL PASS» فقط.
- التدرّج: `linear-gradient(150deg, #1FC8F6 0%, #2D63FC 100%)` — يُستخدم للخلفيات الكبيرة والعناوين الكبيرة فقط.
